# Parlamenti Web API hozzáférés kérés – sablon

**Tárgy:** Web API hozzáférés igénylése – független, nonprofit országgyűlési döntésfigyelő projekt

Tisztelt Országgyűlés Hivatala!

Egy független, nonprofit, nyílt forráskódú, közérthető parlamenti döntésfigyelő weboldal fejlesztéséhez szeretnék hozzáférést igényelni az Országgyűlés nyilvános Web API szolgáltatásához.

A tervezett alkalmazás a benyújtott irományok, kapcsolódó dokumentumok és parlamenti szavazások hivatalos adatait jelenítené meg, eredeti forrásmegjelöléssel. A weboldal nyilvánosan elérhető, nem kereskedelmi célú lenne.

Kérem tájékoztatásukat a regisztráció és a hozzáférési kód igénylésének menetéről, az aktuális XML API dokumentációról, a javasolt lekérdezési gyakoriságról, az esetleges felhasználási feltételekről és a szolgáltatás díjmentességéről.
